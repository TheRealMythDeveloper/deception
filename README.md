# DeSception

**DeSception** is a 2-player multiplayer social deduction game where players ask questions, uncover clues, and try to figure out each other's secret topic without revealing their own.

## How to Play

1. Create a lobby and share the lobby code with another player.
2. Both players select Ready.
3. The host starts the game.
4. Spin the topic wheel to determine the category.
5. Each player receives a secret topic.
6. Take turns asking questions and answering them.
7. After 10 questions, both players submit their final guesses.
8. See the results and play again!

## Game Modes

- **Easy:** Secret topics consist of a single word.
- **Hard:** Secret topics can consist of multiple words, making figuring it out more challenging.

## Features

- Real-time multiplayer using Socket.IO (simplest thing I could find)
- Private secret topics
- Spinning wheels
- Turn-based question and answer system
- Scrollable chat history
- Lobby codes and ready system
- Final guesses and scoring
- Rematch system
- Profanity filtering and message limits
